**Day1**

**1. What is Java?**
Java is a high-level, object-oriented, platform-independent programming language developed by Sun Microsystems in 1995. It is used to develop web, desktop, mobile, and enterprise applications.

**2. Features of Java**
1. Platform Independent: Runs on different operating systems using JVM.
2. Object-Oriented: Based on classes and objects.
3. Simple: Easy syntax compared to languages like C++.
4. Secure: Provides security features like bytecode verification.
5. Robust: Supports exception handling and garbage collection.
6. Multithreaded: Executes multiple tasks simultaneously.
7. Portable: Programs can run on different platforms.
8. High Performance: Uses JIT compilation for faster execution.
   
**3. JDK vs JRE vs JVM**
      JDK	                                JRE	                          JVM
Java Development Kit	            Java Runtime Environment	    Java Virtual Machine
Used to develop Java programs	    Used to run Java programs	    Executes Java bytecode
Contains JRE tools and compiler 	Contains JVM and libraries	  Executes bytecode

**4. Java Architecture**
Java architecture consists of three main components:
- JDK: Provides tools to develop Java programs.
- JRE: Provides the environment to run Java programs.
- JVM: Executes Java bytecode.
Flow: Java Source Code → Compiler → Bytecode → JVM → Machine Code.

**5. Bytecode**
Bytecode is the intermediate code generated by the Java compiler after compiling a .java file. It is stored in a .class file and executed by the JVM.
Example: Hello.java → Hello.class


**Day2**

**1. Variables**
A variable is a named memory location used to store data in a program. Its value can change during program execution.
Syntax:
int age = 22;
String name = "Sumit";

Types of variables:
- Local Variable: Declared inside a method or block.
- Instance Variable: Declared inside a class but outside methods; belongs to an object.
- Static Variable: Declared using static; shared among all objects of a class.

**2. Primitive Data Types**
Primitive data types are the basic built-in types used to store simple values.

Java has 8 primitive data types:
Data Type	Size	Example
byte	1 byte	byte a = 10;
short	2 bytes	short a = 100;
int	4 bytes	int a = 500;
long	8 bytes	long a = 1000L;
float	4 bytes	float a = 10.5f;
double	8 bytes	double a = 20.5;
char	2 bytes	char a = 'A';
boolean	JVM-dependent	boolean a = true;

**3. Reference Types**
Reference types store references to objects rather than directly storing primitive values.

Examples:
- String
- Arrays
- Classes
- Interfaces
- Objects
String name = "Sumit";
int[] numbers = {10, 20, 30};

Difference: Primitive types store actual values, while reference types refer to objects.

**4. Type Casting**
Type casting means converting one data type into another.

There are two types:
1. Widening Casting (Automatic): Smaller data type to larger data type.
int a = 10;
double b = a;
2. Narrowing Casting (Manual): Larger data type to smaller data type.
double a = 10.5;
int b = (int) a;
Output: 10

**5. Literals**
Literals are fixed values directly written in a Java program.

Types:
- Integer: int a = 100;
- Floating-point: double a = 10.5;
- Character: char a = 'A';
- String: String name = "Java";
- Boolean: boolean a = true;
- Null: String s = null;
 
**6. Operators**
Operators are special symbols used to perform operations on variables and values.

A. Arithmetic Operators
Used for mathematical operations.
Operator	Meaning
+	Addition
-	Subtraction
*	Multiplication
/	Division
%	Modulus (remainder)

int a = 10, b = 3;
System.out.println(a % b); // 1


B. Relational Operators
Used to compare two values. Result is always true or false.
==, !=, >, <, >=, <=
System.out.println(10 > 5); // true

C. Logical Operators
Used to combine multiple conditions.

| Operator | Meaning |
|----------|---------|
|   &&     | Logical AND |
|   ||     | Logical OR  |
|   !      | Logical NOT |
int age = 22;
System.out.println(age > 18 && age < 30);


D. Assignment Operators
Used to assign or update values.
=, +=, -=, *=, /=, %=

int a = 10;
a += 5;  // a = 15

E. Unary Operators
Work on a single operand.
- ++ Increment
- -- Decrement
- + Unary plus
- - Unary minus
- ! Logical NOT
int a = 5;
a++;
System.out.println(a); // 6


F. Ternary Operator
A shorthand of the if-else statement. It uses three operands.
Syntax:
condition ? value1 : value2;
Example:
int age = 20;
String result = (age >= 18) ? "Adult" : "Minor";


G. Bitwise Operators
Used to perform operations directly on the binary bits of integer values.
| Operator | Meaning |
|---|---|
| & | Bitwise AND |
| | | Bitwise OR |
| ^ | Bitwise XOR |
| ~ | Bitwise Complement |
| << | Left Shift |
| >> | Signed Right Shift |
| >>> | Unsigned Right Shift |


**Day-3**

**1. if Statement**

The if statement executes a block of code only when the given condition is true.
int age = 20;
if (age >= 18) {
    System.out.println("Eligible to vote");
}

**2. if-else Statement**

The if-else statement executes one block if the condition is true and another block if it is false.
int age = 16;
if (age >= 18) {
    System.out.println("Adult");
} else {
    System.out.println("Minor");
}

**3. Nested Conditions**

An if statement inside another if statement is called a nested if. It is used to check multiple dependent conditions.
int age = 20;
boolean hasLicense = true;

if (age >= 18) {
    if (hasLicense) {
        System.out.println("Can drive");
    }
}

**4. switch Statement**

The switch statement is used to execute different blocks of code based on the value of a variable or expression.
int day = 2;

switch (day) {
    case 1:
        System.out.println("Monday");
        break;
    case 2:
        System.out.println("Tuesday");
        break;
    default:
        System.out.println("Invalid day");
}
Important: break prevents execution from continuing into the next case. default executes when no case matches.

**5. Switch Expressions**

Switch expressions return a value. They were introduced as a standard feature in Java 14.
int day = 2;

String result = switch (day) {
    case 1 -> "Monday";
    case 2 -> "Tuesday";
    case 3 -> "Wednesday";
    default -> "Invalid day";
};
System.out.println(result);
Difference: Traditional switch uses case: and often break; switch expressions use -> and can return values.

**6. Logical Conditions**

Logical operators are used to combine or modify conditions. The result is either true or false.

| Operator | Meaning | Example |
|---|---|---|
| && | AND – Both conditions true | a > 5 && b > 5 |
| || | OR – At least one true | a > 5 || b > 5 |
| ! | NOT – Reverses result | !(a > 5) |

Example:
int age = 22;
boolean hasID = true;

if (age >= 18 && hasID) {
    System.out.println("Entry allowed");
}
Short-circuit: In &&, if the first condition is false, the second is not evaluated. In ||, if the first condition is true, the second is not evaluated.


**Day4**
**1. for Loop**

The for loop is used to execute a block of code repeatedly when the number of iterations is known.

Syntax:
for (initialization; condition; update) {
    // code
}
Example:
for (int i = 1; i <= 5; i++) {
    System.out.println(i);
}

**2. while Loop**

The while loop executes a block of code as long as the condition is true. It is useful when the number of iterations is unknown.

int i = 1;

while (i <= 5) {
    System.out.println(i);
    i++;
}
Note: The condition is checked before execution, so it may execute zero times.

**3. do-while Loop**

The do-while loop executes the code at least once because the condition is checked after execution.

int i = 1;
do {
    System.out.println(i);
    i++;
} while (i <= 5);
Note: A semicolon ; is required after the while condition.

**4. Nested Loops**

A loop inside another loop is called a nested loop. It is commonly used for patterns, matrices, and tables.

for (int i = 1; i <= 3; i++) {
    for (int j = 1; j <= 3; j++) {
        System.out.print("* ");
    }
    System.out.println();
}

**5. break Statement**

The break statement terminates the loop immediately and transfers control to the statement after the loop.

for (int i = 1; i <= 5; i++) {
    if (i == 3) {
        break;
    }
    System.out.println(i);
}
Output: 1 2

**6. continue Statement**

The continue statement skips the current iteration and moves to the next iteration of the loop.

for (int i = 1; i <= 5; i++) {
    if (i == 3) {
        continue;
    }
    System.out.println(i);
}
Output: 1 2 4 5


**Day5**

**1. Methods**
A method is a block of code that performs a specific task. It helps in code reusability and reduces repetition.

Syntax:
returnType methodName() {
    // code
}
Example:
void greet() {
    System.out.println("Hello Java");
}

**2. Parameters**

Parameters are variables declared in a method to receive values from the caller. They allow us to pass data to a method.

void add(int a, int b) {
    System.out.println(a + b);
}
Here, a and b are parameters.

**3. Return Values**

A return value is the result sent back by a method using the return keyword. The return type specifies the type of value returned.

int add(int a, int b) {
    return a + b;
}
int result = add(10, 20);
void means the method does not return a value.

**4. Method Overloading**

Method overloading means defining multiple methods with the same name but different parameter lists. It is an example of compile-time polymorphism.

int add(int a, int b) {
    return a + b;
}
int add(int a, int b, int c) {
    return a + b + c;
}
double add(double a, double b) {
    return a + b;
}
Note: Changing only the return type does not create valid method overloading.

**5. Local / Global Variables**

Variables are classified based on where they are declared.
- Local Variable: Declared inside a method or block. It must be initialized before use and has block-level scope.
- Global Variable: Java does not have true global variables. Instance and static variables are often informally called global variables because they are declared at class level.
  
class Demo {
    int x = 10;          // Instance variable
    static int y = 20;   // Static variable
    void show() {
        int z = 30;      // Local variable
    }
}

**6. Arrays**

An array is a data structure that stores multiple values of the same data type in a fixed-size collection. Array indexing starts from 0.

int[] numbers = {10, 20, 30};
System.out.println(numbers[0]); // 10

**7. 1D Arrays**

A one-dimensional array stores elements in a single sequence.

Declaration:
int[] arr = new int[5];
Initialization:
int[] arr = {10, 20, 30, 40, 50};
for (int i = 0; i < arr.length; i++) {
    System.out.println(arr[i]);
}
arr.length returns the size of the array.

**8. 2D Arrays**

A two-dimensional array stores data in rows and columns. It is commonly used to represent matrices.

Declaration:
int[][] arr = new int[2][3];
Initialization:
int[][] arr = {
    {1, 2, 3},
    {4, 5, 6}
};
for (int i = 0; i < arr.length; i++) {
    for (int j = 0; j < arr[i].length; j++) {
        System.out.print(arr[i][j] + " ");
    }
    System.out.println();
}

Output:
1 2 3
4 5 6

**Day-6**

**1. Class**

A class is a blueprint or template used to create objects. It defines the properties (fields) and behavior (methods) of objects.
class Student {
    String name;
    int age;
}


**2. Object**

An object is an instance of a class. It has state (data) and behavior (methods).
Student s1 = new Student();
s1.name = "Sumit";
s1.age = 22;


Here, s1 is a reference variable pointing to a Student object.


**3. Fields**

Fields are variables declared inside a class but outside methods and constructors. They represent the properties of an object.
class Student {
    String name;  // Field
    int age;      // Field
}


Fields receive default values if not explicitly initialized.


**4. Methods**

Methods are blocks of code defined inside a class that perform specific operations. They represent the behavior of an object.
class Student {
    void display() {
        System.out.println("Hello Student");
    }
}


**5. Constructors**

A constructor is a special member used to initialize an object. It has the same name as the class and does not have a return type.

Types:
- Default constructor: Provided by the compiler if no constructor is declared.
- No-argument constructor: A constructor with no parameters.
- Parameterized constructor: Accepts parameters to initialize values.
class Student {
    String name;

    Student(String name) {
        this.name = name;
    }
}


**6. this Keyword**

The this keyword refers to the current object. It is commonly used to differentiate instance variables from local variables or parameters.
class Student {
    String name;

    Student(String name) {
        this.name = name;
    }
}


Here, this.name refers to the field, while name refers to the constructor parameter.


**7. Instance vs Static Members**

Instance Members	Static Members
Belong to an object	Belong to the class
Each object has its own copy of fields	One shared copy
Accessed using object reference	Accessed using class name
Declared without static	Declared using static

Example:
class Student {
    String name;             // Instance variable
    static String college = "RGPV"; // Static variable

    void display() {
        System.out.println(name);
    }

    static void showCollege() {
        System.out.println(college);
    }
}

Usage:
Student s1 = new Student();
s1.name = "Sumit";

Student.showCollege();

Important: Static methods cannot directly access instance members because they do not belong to a particular object


**Day7**

**1. Access Modifiers**

Access modifiers define the visibility or accessibility of classes, variables, methods, and constructors. Java has four access levels: public, private, protected, and default.

**2. private**

The private modifier allows access only within the same class. It is commonly used to protect data.
private int age;


**3. public**

The public modifier allows access from anywhere, provided the class itself is accessible.
public void display() {
    System.out.println("Hello");
}


**4. protected**

The protected modifier allows access within the same package and also in subclasses outside the package.
protected int salary;


**5. default**

When no access modifier is specified, it is called default or package-private access. It allows access only within the same package.
int age;

Access Modifier Table
Modifier	Same Class	Same Package	Subclass (Other Package)	Other Package
private	Yes	No	No	No
default	Yes	Yes	No	No
protected	Yes	Yes	Yes	No
public	Yes	Yes	Yes	Yes

**6. Getters**

A getter is a method used to retrieve the value of a private variable. It usually starts with get.
public int getAge() {
    return age;
}


**7. Setters**

A setter is a method used to modify the value of a private variable. It usually starts with set.
public void setAge(int age) {
    this.age = age;
}


**8. Data Hiding**

Data hiding is the process of restricting direct access to class data by declaring fields as private and providing controlled access through getters and setters.

Example:
class Student {
    private int age;

    public int getAge() {
        return age;
    }

    public void setAge(int age) {
        if (age > 0) {
            this.age = age;
        }
    }
}

Usage:
Student s = new Student();
s.setAge(22);
System.out.println(s.getAge());

Benefits:
- Protects data from unauthorized access.
- Provides controlled modification.
- Improves security and maintainability.
