**1. What is Java?**
Java is a high-level, object-oriented, platform-independent programming language developed by Sun Microsystems in 1995. It is used to develop web, desktop, mobile, and enterprise applications.

**2. Features of Java**
1. Platform Independent: Runs on different operating systems using JVM.
2. Object-Oriented: Based on classes and objects.
3. Simple: Easy syntax compared to languages like C++.
4. Secure: Provides security features like bytecode verification.
5. Robust: Supports exception handling and garbage collection.
6. Multithreaded: Executes multiple tasks simultaneously.
7. Portable: Programs can run on different platforms.
8. High Performance: Uses JIT compilation for faster execution.
   
**3. JDK vs JRE vs JVM**
      JDK	                                JRE	                          JVM
Java Development Kit	            Java Runtime Environment	    Java Virtual Machine
Used to develop Java programs	    Used to run Java programs	    Executes Java bytecode
Contains JRE tools and compiler 	Contains JVM and libraries	  Executes bytecode

**4. Java Architecture**
Java architecture consists of three main components:
- JDK: Provides tools to develop Java programs.
- JRE: Provides the environment to run Java programs.
- JVM: Executes Java bytecode.
Flow: Java Source Code → Compiler → Bytecode → JVM → Machine Code.

**5. Bytecode**
Bytecode is the intermediate code generated by the Java compiler after compiling a .java file. It is stored in a .class file and executed by the JVM.
Example: Hello.java → Hello.class


**Day2**
**1. Variables**
A variable is a named memory location used to store data in a program. Its value can change during program execution.
Syntax:
int age = 22;
String name = "Sumit";

Types of variables:
- Local Variable: Declared inside a method or block.
- Instance Variable: Declared inside a class but outside methods; belongs to an object.
- Static Variable: Declared using static; shared among all objects of a class.

**2. Primitive Data Types**
Primitive data types are the basic built-in types used to store simple values.

Java has 8 primitive data types:
Data Type	Size	Example
byte	1 byte	byte a = 10;
short	2 bytes	short a = 100;
int	4 bytes	int a = 500;
long	8 bytes	long a = 1000L;
float	4 bytes	float a = 10.5f;
double	8 bytes	double a = 20.5;
char	2 bytes	char a = 'A';
boolean	JVM-dependent	boolean a = true;

**3. Reference Types**
Reference types store references to objects rather than directly storing primitive values.

Examples:
- String
- Arrays
- Classes
- Interfaces
- Objects
String name = "Sumit";
int[] numbers = {10, 20, 30};

Difference: Primitive types store actual values, while reference types refer to objects.

**4. Type Casting**
Type casting means converting one data type into another.

There are two types:
1. Widening Casting (Automatic): Smaller data type to larger data type.
int a = 10;
double b = a;
2. Narrowing Casting (Manual): Larger data type to smaller data type.
double a = 10.5;
int b = (int) a;
Output: 10

**5. Literals**
Literals are fixed values directly written in a Java program.

Types:
- Integer: int a = 100;
- Floating-point: double a = 10.5;
- Character: char a = 'A';
- String: String name = "Java";
- Boolean: boolean a = true;
- Null: String s = null;
 
**6. Operators**
Operators are special symbols used to perform operations on variables and values.

A. Arithmetic Operators
Used for mathematical operations.
Operator	Meaning
+	Addition
-	Subtraction
*	Multiplication
/	Division
%	Modulus (remainder)

int a = 10, b = 3;
System.out.println(a % b); // 1


B. Relational Operators
Used to compare two values. Result is always true or false.
==, !=, >, <, >=, <=
System.out.println(10 > 5); // true

C. Logical Operators
Used to combine multiple conditions.

| Operator | Meaning |
|----------|---------|
|   &&     | Logical AND |
|   ||     | Logical OR  |
|   !      | Logical NOT |
int age = 22;
System.out.println(age > 18 && age < 30);


D. Assignment Operators
Used to assign or update values.
=, +=, -=, *=, /=, %=

int a = 10;
a += 5;  // a = 15

E. Unary Operators
Work on a single operand.
- ++ Increment
- -- Decrement
- + Unary plus
- - Unary minus
- ! Logical NOT
int a = 5;
a++;
System.out.println(a); // 6


F. Ternary Operator
A shorthand of the if-else statement. It uses three operands.
Syntax:
condition ? value1 : value2;
Example:
int age = 20;
String result = (age >= 18) ? "Adult" : "Minor";


G. Bitwise Operators
Used to perform operations directly on the binary bits of integer values.
| Operator | Meaning |
|---|---|
| & | Bitwise AND |
| | | Bitwise OR |
| ^ | Bitwise XOR |
| ~ | Bitwise Complement |
| << | Left Shift |
| >> | Signed Right Shift |
| >>> | Unsigned Right Shift |
